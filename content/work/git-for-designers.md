# Git for Designers

A practical guide that explains Git through the concerns and working habits of designers who have never used version control before.

## Context

Designers increasingly work closer to production code, prototypes, and AI-assisted development environments. Git is often the missing piece that makes those workflows safer and more collaborative.

## Challenge

Most Git tutorials are written for software engineers and assume familiarity with command-line concepts. The project needed to make Git approachable without oversimplifying its real value.

## Approach

The guide uses visual metaphors, practical examples, and a progressive workflow covering repositories, commits, branches, merging, and collaboration.

## Outcome

A standalone educational resource that designers can read, download, and use as a reference while adopting Git in their everyday practice.
