# Editorial OS v1.0

A publishing system for thoughtful creators.

## Foundations

### Typography

- Display: Newsreader
- Interface and long-form body: Manrope
- Metadata and code: DM Mono

### Color

- Paper: `#f2f0e9`
- Ink: `#11110f`
- Muted: `#6d6b64`
- Accent: `#ff5a36`

### Principles

1. Reading comes first.
2. Calm by default.
3. Build, do not decorate.
4. Publish in durable formats.
5. Use the ✳ as identity, not ornament.

## Implemented in v1.0

- Final homepage hero and publication positioning
- Balanced responsive hero typography
- Reading-focused article width and rhythm
- Refined headings, links, quotes, images, lists, and code
- Two-pixel reading progress indicator
- Quiet end-of-article signature
- Existing Markdown/GitHub content workflow preserved
- Existing project case-study layout preserved
